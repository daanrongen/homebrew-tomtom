# homebrew-tomtom

[Homebrew](https://brew.sh) tap for [`tomtom`](https://github.com/daanrongen/tomtom), a Unix-friendly CLI for TomTom's location APIs.

```sh
brew tap daanrongen/tomtom
brew install tomtom
```

`Formula/tomtom.rb` is generated and pushed here automatically by [tomtom's release workflow](https://github.com/daanrongen/tomtom/blob/main/.github/workflows/release.yml) on every tagged release — don't edit it by hand.
